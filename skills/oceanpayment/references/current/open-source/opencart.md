# 


## 概述
OpenCart是世界著名的开源电子商务系统，系统开发语言为PHP。项目托管在GitHub。开发者项目非常活跃，版本更新升级很快。据Alexa网站流量统计显示，OpenCart 已成为世界主流的电子商务建站系统。

## 安装
1. 上传Oceanpayment支付插件至网站根目录；
2. 启用支付插件；
3. 配置Oceanpayment账户信息。

## 配置
<div className="table-container">
|配置|选项|
| --- | --- |
|Account|Provide by Oceanpayment technical support.|
|Terminal|Provide by Oceanpayment technical support.|
|SecureCode|Provide by Oceanpayment technical support.|
|Oceanpayment transation URL|• Production environment: https://secure.oceanpayment.com/gateway/service/pay<br/>• Sandbox environment: https://test-secure.oceanpayment.com/gateway/service/pay|
|Pay Mode|• Redirect: Redirect to open payment page<br/>• Iframe: iframe payment page.|
|Default Order Status|Pending|
|Success Order Status|Processed|
|Failed Order Status|Failed|
|Pending Order Status|Pending|
|Geo Zone|All Zones.|
|Response Code Mode|Local.|
