# 

## 概述
在对接Oceanpayment接口过程中，系统可能返回不同的错误响应代码。 商户系统需要根据错误代码进行正确的识别和处理，以保障业务流程的稳定性。

## 响应代码
查看OPCCOUNT完整[响应代码](/docs/response-code/opccount)以及错误说明。

## 处理流程
1. **接收接口响应**  
   - 系统调用Oceanpayment接口后，首先接收返回的响应码与描述信息。  

2. **判断是否成功**  
   - 若响应结果为成功（例如状态码为 `200`），继续后续业务处理。  
   - 若返回错误码，则进入错误处理流程。  

3. **分类处理错误类型**  

4. **记录日志**  
   - 对所有错误响应进行日志记录，方便后续排查与审计。  

5. **通知用户或人工介入**  
   - 需要用户操作时（如更换银行卡），提示用户；  
   - 系统异常时，通知技术人员人工介入处理。
