#

## 对接模式
### 📌直连模式
 无需跳转Oceanpayment完成支付。
<img src={require('/img/cn/saas/direct-page.png').default} className="image-card"/>
### 📌跳转模式
跳转至Oceanpayment或银行托管页面完成支付。  
<img src={require('/img/cn/saas/redirect-page.png').default} className="image-card"/>

## 安装指引
### ![Shopify](/img/cn/saas/shopify.png)
:::warning[注意]
- Shopify店铺**只能安装一种直连信用卡**，如果您安装其他直连信用卡，则需要**卸载**，才能安装Oceanpayment直连信用卡；  
- 信用卡跳转模式和所有的本地支付可以**同时对接多个**，和其他第三方支付同时安装也不会冲突；  
- 使用🎯[**Shopify Payments开启多币种结账**](https://help.shopify.com/zh-CN/manual/payments/shopify-payments/store-currency/multi-currency)，第三方支付除Shopify Payments和Adyen之外，都不支持多币种结账。
:::
