#

### 概述
在您的Shopify店铺安装`Oceanpayment Connect` APP，Shopify会自动同步订单的物流信息至Oceanpayment，您可以通过它来查询Oceanpayment的订单，也可以用来修改店铺页面和支付Logo等。
:::warning[注意]
`Oceanpayment Connect`只适用于Shopify店铺。
::: 

### 安装
1. 访问Oceanpayment Connect安装链接：[https://apps.shopify.com/oceanpayment-order-management-1](https://apps.shopify.com/oceanpayment-order-management-1)
<img src={require('/img/cn/saas/app/connect.png').default} className="image-card"/>


### 物流同步
`Oceanpayment Connect` APP安装完成后，您需要先在Shopify店铺上传订单的物流信息，此后Shopify会自动同步物流信息至Oceanpayment。
:::warning[注意]
当`Oceanpayment Connect` 被卸载后，物流信息不会再自动同步至Oceanpayment。
:::
